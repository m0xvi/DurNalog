# Турналог 3.0 — редизайн GUI

Интерактивный прототип: `turnalog-redesign.html`  
Стек без изменений: **Python · customtkinter · ttk.Treeview · PyInstaller**.

Светлая тема фиксирована, как в текущем 2.6.

---

## Что было не так

| Было | Почему мешает бухгалтеру |
|---|---|
| Серые панели на сером фоне | Нет иерархии: шаг 1, шаг 2 и фон сливаются |
| Пустые `CTkEntry` + «Обзор…» | Не видно, выбран ли файл, что в нём лежит |
| Квартал и дубли спрятаны в подписи к зелёной кнопке | Главные параметры расчёта не на виду |
| 6 вкладок в одну строку в «Настройках» | «Агенты / Пользователи / Данные» теряются рядом с отелями |
| Формулы Excel всегда на экране | Пугают неустойчивых; нужны 2% пользователей |
| Пустая «История» без состояния | Непонятно, сломалось или просто нет отчётов |
| Сайдбар светло-серый, как контент | Навигация не отделена от рабочей зоны |

## Принципы

1. **Один экран — одно действие.** Обработка отеля / история / настройки.
2. **Файл как объект**, не как путь в текстовом поле.
3. **Квартал — управление, не сноска.**
4. **Сложное прячем.** Формулы — в раскрывающийся блок.
5. **Цвет отеля.** Точка у названия: Чайковский — бирюза, Дона — янтарь, Усадьба — роза. Тот же цвет в истории.
6. **Реализуемо в customtkinter** — скругления, карточки, сплошные цвета, без стекла и градиентов контента.

## Раскладка окон

### Главное (`CTk`)

```
┌ titlebar ─────────────────────────────────────────┐
│ sidebar 232px │  page (scroll)                    │
│ navy          │  заголовок отеля + чипы           │
│ отели         │  ┌ шаг 1 ─────────┐┌ шаг 2 ─────┐ │
│ история       │  │ drop Данные    ││ квартал    │ │
│ настройки     │  │ drop Номера    ││ дубли      │ │
│ admin / 2.6   │  │ колонки        ││ [ОБРАБОТАТЬ]│ │
│               │  └────────────────┘└────────────┘ │
│               │  3 мини-карточки последней обработки
├ statusbar: точка · текст · путь к БД ─────────────┤
```

Сайдбар — `CTkFrame(fg_color=sidebar)`, пункты — `CTkButton` с `fg_color=transparent` / active `#31476A`, `anchor="w"`.

Зона файла — `CTkFrame` с пунктиром (нарисовать через `Canvas.create_rectangle(dash=(4,3))` либо сплошная рамка `#C5D2E0` + иконка). По клику — прежний `filedialog`. После выбора: зелёный фон `#E5F7EE`, имя файла, кнопка «Заменить».

Квартал — четыре `CTkButton` в сегменте + `CTkEntry` год.  
CTA «Обработать и сохранить» **disabled**, пока не выбран файл «Данные».

Фиолетовая подсказка про переход кварталов — `CTkFrame(fg_color="#F3E8FF")`.

### Настройки — отдельное `CTkToplevel`

Вместо 6 вкладок в ряд:

*слева* узкий `CTkScrollableFrame` (Отели / Справочники / Система)  
*справа* контент выбранного раздела  
*снизу* Сохранить / Отмена — прибиты, не уезжают со скроллом

Формулы Excel — `CTkFrame`, по умолчанию свёрнут (`pack_forget` / кнопка «Шаблоны формул»).

Агенты: master–detail как сейчас, но список с инициалами и поиском сверху. «Применяется к» — три `CTkCheckBox` в ряд, не смесь radio/check.

Пользователи: `ttk.Treeview` + тэг роли (админ — синий, отель — бирюза). Стиль Treeview:

```python
style = ttk.Style()
style.theme_use("clam")
style.configure("Treeview",
    background="#FFFFFF", fieldbackground="#FFFFFF",
    foreground="#1A2332", rowheight=32, font=("Segoe UI", 10))
style.configure("Treeview.Heading",
    background="#F7F9FC", foreground="#5C6B80",
    font=("Segoe UI", 9, "bold"))
style.map("Treeview", background=[("selected", "#EAF1FF")],
          foreground=[("selected", "#1A2332")])
```

### История

Те же кнопки, плюс поиск. Под таблицей — панель перехода кварталов с пустым состоянием (иконка + одна фраза), а не голый белый прямоугольник.

## Соответствие виджетов

| Макет | Виджет |
|---|---|
| Сайдбар, карточки, дроп-зоны | `CTkFrame` |
| Пункты навигации, CTA, Обзор | `CTkButton` |
| Год, формулы, синонимы, ставка | `CTkEntry` |
| Чекбоксы расчёта / дублей | `CTkCheckBox` |
| Настройки: левая колонка | кнопки, не `CTkTabview` |
| История, пользователи | `ttk.Treeview` + clam-стиль |
| Файлы / сообщения | `filedialog` / `messagebox` как сейчас |
| Тост «сохранено» | маленький `CTkToplevel` без рамки, 2.5 с, правый низ |

Иконки — PNG 16×16 в `assets/` (Pillow), либо символ в тексте кнопки. Не нужен кастомный titlebar: оставить системный Windows.

5. Формулы свернуть.
6. Treeview-стиль + пустые состояния.
7. Тост вместо части `messagebox.showinfo`.
