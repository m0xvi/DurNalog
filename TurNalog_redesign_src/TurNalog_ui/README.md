# Турналог — только GUI (редизайн)

Графическая часть макета на **customtkinter**. Расчёта, pandas, sqlite и Excel **нет**.

Запускать рядом с существующим `dist\TurNalog`, не вместо него.

## Запуск

```text
pip install -r requirements.txt
python app.py
```

Windows, светлая тема. Нужен Python с tkinter (обычно уже есть).

Скриншоты с прогона GUI: `screenshots/`.

## Что работает

- Сайдбар: Чайковский / Дона / Усадьба / История / Настройки
- Зоны файлов → `filedialog` (путь хранится, файл не читается)
- Квартал, год, чекбокс дублей
- «Обработать и сохранить» активна после выбора «Данные» → диалог имени файла → заглушка
- История: таблица `ttk.Treeview`, открыть/удалить — заглушки
- Настройки: левое меню, параметры отеля, свёрнутые формулы, агенты, пользователи, путь БД
- Сопоставление колонок

## Куда вставлять боевой код

В `app.py`, методы:

| Метод | Сюда из 2.6 |
|---|---|
| `hook_process(...)` | пайплайн обработки и сохранения xlsx |
| `hook_open_file(...)` | открытие оригинала / результата |
| `hook_save_settings(...)` | запись json/sqlite настроек |
| `hook_save_columns(...)` | сопоставление колонок по отелю |

Демо-цифры (128 450 ₽, `chai_buh`) не писать в БД.

Цвета — `theme.py` → `COLORS`.

Подробные правила: `../ПЕРЕДАЧА_РАЗРАБОТЧИКУ.md`.
